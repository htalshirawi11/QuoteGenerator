# Quote Generator

A react web application that can display random quotes from a fetched API. You can also add your own quotes in.

[Vercel link to go try it out live!
]([url](https://quote-generator-tan-five.vercel.app/))
## Features
- Fetches random quotes
- "New Quote feature" - adds more to your library
- Displays quote and author
- Smooth transitions between the gradient backgrounds
- Fully responsive, clean UI

## Tech Stack
- React (Vite)
- CSS (Flexbox, gradients and transitions)
- API Ninjas (fetch) https://api-ninjas.com/api
